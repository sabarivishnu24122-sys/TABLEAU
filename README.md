# NYC TLC Trip data using Tableau

In this project, we created detailed analysis of trip demand and revenue using **Tableau Desktop**.

The dataset was sourced from this link:[NYC TLC trip data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)

**Outcomes of the project:**

* North Harlem South had the most number of trips in a single day.*
* Overall, the demand was higher in the evenings.*
* The zones with most demand is not associated with maximum average revenue.*
